## Create C3FO App

A quick start to begin using C3FO. This is now the recommended way to start your project with C3FO.

## Usage

Just run:

```
npx create-c3fo
```

Or:

```
npx create-c3fo your-project-name
```

And that's it! Wait for the download and cd into your project directory! If everything went well, you can run:

```
npm run dev
```

## How it works?

This CLI tool internally fetches and updates, with your information, the starter templates of your choosing:

- [Starter for plugin & addons](https://github.com/C3Framework/framework)
- [Starter for themes](https://github.com/C3Framework/template-theme)
